# Interior Design Studio

## Description

Le projet **Interior Design Studio** est en cours de développement, visant à créer un site web pour un studio de design d'intérieur. Ce projet utilise plusieurs solutions techniques avancées telles que Scrolltrigger, BarbaJS, Textsplit, et des sliders pour offrir une expérience utilisateur exceptionnelle. Les technologies principales utilisées incluent Blade.php, SCSS, ViteJS, et JavaScript sans jQuery.

## Tâches

Le projet est découpé en plusieurs tâches essentielles, chacune contribuant à l'achèvement réussi du site web du studio de design d'intérieur :

- [x] **Définir les Points Clés du Projet** - Cette étape a permis de clarifier les objectifs et les exigences du projet.

- [ ] **Initialisation du Projet** - La mise en place de l'environnement de développement est la prochaine étape cruciale.

- [ ] **Création de la Structure HTML** - La structure HTML du site doit être conçue pour garantir une base solide.

- [ ] **Application du Style à la Structure** - L'application des styles CSS au contenu est essentielle pour rendre le site visuellement attrayant.

- [ ] **Développement des Animations** - Les animations spécifiques au projet, visibles [ici](https://www.behance.net/gallery/173523307/Interior-Design-Studio-Website), seront mises en œuvre pour une expérience utilisateur immersive.


## Solutions Techniques

Le projet utilise plusieurs solutions techniques pour atteindre ses objectifs :

- **Scrolltrigger (GSAP)** - Utilisé pour créer des animations basées sur le défilement, offrant une expérience interactive.

- **BarbaJS** - Permet la transition en douceur entre les pages, améliorant la fluidité de la navigation.

- **Textsplit (GSAP)** - Utilisé pour les animations de texte pour rendre le contenu plus dynamique.

- **Slider (x2)** - Deux sliders sont prévus pour afficher des images et des projets de design d'intérieur.

## Technologies Utilisées

Les technologies principales utilisées dans ce projet sont les suivantes :

- **Blade.php** - Un moteur de modèle efficace pour PHP, permettant une gestion facile des vues.

- **SCSS (arbo 5.1)** - Une extension de CSS qui simplifie la gestion des styles tout en offrant de nombreuses fonctionnalités avancées.

- **ViteJS** - Un outil de build rapide et minimaliste pour les projets JavaScript.

- **JS (sans jQuery)** - Le JavaScript est utilisé pour créer des fonctionnalités interactives sans dépendre de jQuery.
